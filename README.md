# DriesWoodworks

Statische Website für DriesWoodworks – handgedrechselte Holzstücke aus dem Odenwald.

Einfach `index.html` im Browser öffnen, oder den Ordner über GitHub Pages / einen beliebigen Webspace ausliefern. Kein Build-Schritt nötig.

- `index.html` – Inhalt
- `styles.css` – Gestaltung (Farben als Variablen in `:root`)
- `images/` – Produktfotos
